# Downfall

У Downfall ви керуєте героєм під час падіння у прірву. Атакуйте ривком униз і відскакуйте вгору, щоб обрати місце наступного удару. Для перемоги потрібно здолати трьох босів на глибині 500, 1000 і 1500 метрів.

## Можливості

- Три біоми з різними ворогами й пастками. У храмі є руничні промені, у грибних печерах отруйні хмари, у вугільній безодні вибухові міни.
- 18 мутацій, які змінюють бій. Можна заморожувати ворогів, запускати ланцюгові блискавки, отримати щит або додатковий заряд ривка.
- Боси з двома фазами. Дзвонар атакує звуковими стовпами, Спорова Матір викликає прислужників, Серце Кузні перекриває шлях вогняними заслонами.
- Піксельне оформлення та сім музичних тем для меню, біомів і босів.
- Керування клавіатурою та екранні кнопки для сенсорних пристроїв.

## Запуск

Завантажте [архів із грою](https://github.com/mEzye/downfall/archive/refs/heads/main.zip), розпакуйте його й відкрийте `index.html` у Chrome, Edge або Firefox. Гра працює офлайн.

Для запуску через локальний сервер на Windows:

```powershell
git clone https://github.com/mEzye/downfall.git
cd downfall
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

Відкрийте [localhost:4173](http://localhost:4173). Щоб зупинити сервер, натисніть Ctrl+C у його вікні.

Якщо браузер блокує автоматичний звук, натисніть на меню або кнопку звуку. Гра запам'ятовує вимкнення звуку та найкращу глибину в цьому браузері.

## Керування

| Клавіші | Дія |
| --- | --- |
| A / D або стрілки ліворуч і праворуч | Рух у повітрі |
| Space, S або стрілка вниз | Ривок униз |
| Shift, утримувати | Уповільнення часу |
| 1 / 2 / 3 | Вибір мутації |
| Esc або P | Пауза |
| M | Увімкнення та вимкнення звуку |

На сенсорному пристрої використовуйте кнопки внизу екрана. Якщо перейти до іншого вікна, гра стане на паузу. Перед продовженням є короткий відлік.

## Як грати

Ривок пробиває ворогів, снаряди та крихкі платформи. Убивство ривком повертає заряд і підкидає героя вгору. Шипи, активні промені та вогняні заслони залишаються небезпечними під час ривка.

Гриби, призми, кільця та кам'яні платформи підкидають угору при приземленні. Керуйте героєм у повітрі, щоб продовжити падіння в іншому місці. Об'єкт витримує три відскоки. Лише перший контакт повертає заряд.

Щоб поповнити фокус, пролетіть біля краю світлого обідка ворога без зіткнення та без ривка. Успішне ухилення дає 20 фокусу. Утримуйте Shift, щоб витратити його на уповільнення часу.

Кожні 250 метрів можна вибрати одну з трьох випадкових мутацій. Їхні ефекти поєднуються. Вибір мутації дає заряд і трохи фокусу, але не лікує автоматично. Глибина збільшується лише тоді, коли герой опускається нижче попередньої найглибшої точки.

У бою з босом атакуйте світле ядро ривком. Після влучання герой відскакує вгору. Перші дві перемоги відновлюють одне серце й відкривають наступний біом. Поразка завершує забіг, після неї можна почати новий.

## Для розробників

Гра написана на JavaScript і використовує Canvas 2D та Web Audio. Для запуску з коду не потрібні збірка чи встановлення пакетів.

- `game.js` містить ігрову логіку, малювання та синтез звуку.
- `content.js` містить босів, музичні теми та числа балансу в об'єкті `balance`.
- `index.html` і `style.css` задають меню та ігрові індикатори.
- `start.ps1` запускає локальний сервер для Windows.

F3 показує частоту кадрів, час роботи JavaScript і малювання та кількість об'єктів у сцені.
